零基础上手：MySQL 核心基础知识全解析

在后端开发中，数据库技术是重中之重。本文整理了 MySQL 的核心基础知识，包括 SQL 分类、数据库/表操作、复杂查询、内置函数、约束机制以及事务管理。建议收藏作为你的 SQL 工具字典！

一、 SQL 分类

SQL 语言根据功能主要分为四类：

  • DDL (Data Definition Language): 数据定义语言，定义数据库对象（数据库、表、字段）。
  • DML (Data Manipulation Language): 数据操作语言，对表数据进行增删改。
  • DQL (Data Query Language): 数据查询语言，查询表记录。
  • DCL (Data Control Language): 数据控制语言，创建用户及控制访问权限。

四、 DQL：玩转数据查询（核心）

查询语句的编写顺序为：SELECT -> FROM -> WHERE -> GROUP BY -> HAVING -> ORDER BY -> LIMIT。

1. 基础与条件查询

  • 去重: SELECT DISTINCT address FROM emp;
  • 模糊匹配: LIKE（_ 匹配单个字符，% 匹配任意个字符）。
    • 示例：查询姓名两个字的：WHERE name LIKE '__';
    • 示例：查询身份证末尾是X的：WHERE idcard LIKE '%X';

2. 聚合函数

常用：COUNT (总数), MAX (最大), MIN (最小), AVG (平均), SUM (求和)。

3. 分组查询 (GROUP BY)

注意：WHERE 在分组前过滤，HAVING 在分组后过滤（可判断聚合函数）。

4. 排序与分页

  • 排序: ORDER BY 字段1 ASC (升序), 字段2 DESC (降序);
  • 分页: LIMIT 起始索引, 查询记录数;（起始索引 = (页码 - 1) * 每页条数）。

五、 常用内置函数

1. 字符串函数

  • CONCAT(s1, s2): 拼接。
  • LPAD / RPAD: 左右填充（常用于补齐工号）。
  • SUBSTRING(str, start, len): 截取（索引从1开始）。

2. 数值函数

  • CEIL(x): 向上取整；FLOOR(x): 向下取整。
  • ROUND(x, y): 四舍五入保留 y 位。

3. 日期函数

  • CURDATE(), NOW(): 获取当前日期、时间。
  • DATEDIFF(d1, d2): 日期差。

4. 流程函数

  • IF(val, t, f): 三元运算。
  • CASE WHEN ... THEN ... ELSE ... END: 条件分支。

六、 约束与多表关联

1. 约束分类

  • NOT NULL (非空), UNIQUE (唯一), PRIMARY KEY (主键), DEFAULT (默认值), CHECK (检查), FOREIGN KEY (外键)。

2. 多表查询

  • 内连接: SELECT ... FROM A INNER JOIN B ON A.id = B.a_id;
  • 外连接: LEFT JOIN (左表全显示) / RIGHT JOIN (右表全显示)。
  • 自连接: 自己连自己，必须起别名。
    • SELECT a.name, b.name FROM emp a JOIN emp b ON a.managerid = b.id;
  • 联合查询 (UNION): 合并结果集（UNION ALL 不去重，UNION 去重）。

3. 子查询

根据返回结果分为：

  • 标量子查询（单行单列）：WHERE id = (SELECT id ...)
  • 列子查询（一列多行）：常用 IN, ANY, ALL。
  • 行子查询（一行多列）：WHERE (salary, managerid) = (SELECT ...)
  • 表子查询（多行多列）：常放在 FROM 后作为临时表。

七、 事务管理 (Transaction)

事务是一组操作的集合，必须作为一个整体执行。

1. 事务控制

2. 四大特性 (ACID)

  1. 原子性 (Atomicity): 要么全部成功，要么全部失败。
  2. 一致性 (Consistency): 事务完成后数据状态保持一致。
  3. 隔离性 (Isolation): 并发事务互不干扰。
  4. 持久性 (Durability): 一旦提交，改变是永久的。

3. 并发事务问题与隔离级别

  • 问题: 脏读（读到未提交）、不可重复读（两次读到数据不同）、幻读（查询没记录但插入报错）。
  • 隔离级别:
    隔离级别 脏读 不可重复读 幻读
    Read Uncommitted 会 会 会
    Read Committed 不会 会 会
    Repeatable Read (MySQL默认) 不会 不会 会
    Serializable 不会 不会 不会
