一、 认识 Linux 的“家谱”：目录结构

Linux 的世界里“一切皆文件”，了解目录结构是第一步：

  • /：根目录，所有路径的起点。
  • /root：超级管理员 root 的家目录。
  • /home：普通用户的家目录。
  • /usr：系统应用程序存放地（类似 Windows 的 Program Files）。
  • /etc：系统及软件的配置文件存放目录。
  • /var：存放经常变化的文件，如日志文件。

二、 基础操作与快捷技巧

1. 获取服务器 IP

  • 命令：ifconfig 或 ip addr。

2. 效率三宝

  • Tab 键：命令或路径自动补全（最常用）。
  • 上下方向键：快速调回之前输入过的历史命令。
  • Ctrl + C：强制停止当前正在运行的程序/命令。

三、 文件与目录管理（核心操作）

1. 路径导航

  • pwd：查看当前所在位置的绝对路径。
  • ls：列出当前目录下的文件（ls -al 查看详细及隐藏文件）。
  • cd：切换目录。
    • cd .. 返回上一层；cd ~ 回到家目录。

2. 增删改查

  • 创建：mkdir 创建文件夹，touch 创建空文件。
  • 复制 (cp)：
    • cp aa.txt adir/ (复制文件)
    • cp -r bdir/ cdir/ (复制文件夹，必须带 -r)
  • 移动/改名 (mv)：mv aa.txt bdir/。
  • 删除 (rm)：
    • rm -i file (删除前提示)
    • rm -rf * (危险！ 递归强制删除当前所有文件)
    • 禁忌命令：rm -rf /* (删库跑路专用，严禁使用)。

四、 文本查看与搜索：日志监控神器

1. 查看内容

  • cat：一次性展示全部内容。
  • more / less：分屏查看长文件。
  • head -n 15：查看前 15 行。
  • tail -f log.txt：实时滚动查看日志（调试程序必备）。

2. 搜索与过滤（管道符）

  • grep：文本搜索。
  • | (管道符)：将前一个命令的结果交给后一个命令处理。
    • 示例：ls -al /usr/bin | grep mysql (在列表中查找包含 mysql 的项)。

五、 进程与端口管理：掌控系统运行情况

1. 进程监控

  • ps -aux：查看系统所有运行中的进程。
  • top：实时查看 CPU、内存占用情况（类似任务管理器）。
  • 强杀进程：先用 ps 找 PID，再执行 kill -9 <PID>。

2. 端口与网络

  • netstat -anptu | grep 端口号：查看哪个程序占用了端口。
  • lsof -i:端口号：另一种查询端口占用的常用方法。
  • 常见端口：SSH(22), HTTP(80), HTTPS(443), MySQL(3306)。

六、 权限与用户管理

1. 修改权限 (chmod)

Linux 权限分为：R(读:4), W(写:2), X(执行:1)。

  • 数字法：chmod 755 file (拥有者全权，其余人可读可执行)。
  • 字母法：chmod u=rwx,g=rx,o=x file。

2. 用户切换

  • whoami：查看当前用户名。
  • su -：切换到 root 用户。

七、 压缩、链接与查找

1. 压缩解压 (tar)

  • 压缩：tar -zcvf test.tar.gz ./test/
  • 解压：tar -zxvf test.tar.gz -C ./target/

2. 查找文件 (find)

  • find /home -name "demo.txt"：在指定目录下按名称查找文件。

3. 软链接 (ln)

  • ln -s 原文件 快捷方式：创建软链接（类似 Windows 快捷方式）。

八、 文本编辑与软件安装

1. Vi/Vim 编辑器

  1. 输入 vi 文件名 进入预览。
  2. 按 i 进入编辑模式。
  3. 编辑完按 Esc 退出编辑。
  4. 输入 :wq 保存退出，输入 :q! 不保存强制退出。

2. 软件包管理 (Yum)

  • 安装软件：yum install <名称>
  • 删除软件：yum remove <名称>
  • 查找清单：yum list

结语：Linux 的指令虽然繁多，但最常用的不过几十个。多在服务器上敲几遍，你会发现它比图形化界面更加高效、强大！
